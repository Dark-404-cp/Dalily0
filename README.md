# دليلى (Dalily) — سوق إكسسوارات الهواتف المحلية

منصة تسوق إلكتروني وسوق محلي متخصص في ملحقات وإكسسوارات الهواتف الذكية (جرابات، اسكرينات، شواحن، كابلات) مبنية باستخدام **HTML5, CSS3, Vanilla JavaScript** بدون أي مكتبات أو خوادم خلفية، وتعمل بنظام تطبيق الصفحة الواحدة (Single Page Application - SPA) مع حفظ كامل للبيانات عبر `localStorage`.

---

## 🚀 طريقة التشغيل (How to Run)

المشروع جاهز تمامًا للتشغيل بدون الحاجة إلى أي خطوات تثبيت أو بناء (No Build Step):

1. افتح الملف `index.html` مباشرة في أي متصفح حديث (Google Chrome, Microsoft Edge, Firefox, Safari).
2. أو قم بتشغيل خادم محلي خفيف مثل:
   ```bash
   npx serve .
   # أو
   python -m http.server 8000
   ```

---

## 🔑 بوابات الحسابات المستقلة (Independent Account Portals)

تم فصل الحسابات بالكامل بحيث يمتلك كل دور بوابته وتجربته المستقلة:

1. **بوابة العملاء (Customer Portal):**
   - تسجيل الدخول (`user` / `user`) أو إنشاء حساب عميل جديد بالاسم وكلمة المرور.
   - **خاصية هامة:** عند دخول العميل، **تختفي "لوحة التحكم" تماماً** من الشريط العلوي ولا يظهر له سوى شارة اسمه وزر خروج، مع منع وصوله للوحات التجار والإدارة.

2. **بوابة التجار (Store Owner Portal):**
   - تسجيل الدخول (`Store Owner` / `Store Owner`).
   - يدخل مباشرة إلى لوحة تحكم التاجر لإدارة المحل، المخزون، الاستيراد، ومتابعة المبيعات.

3. **بوابة الإدارة (Admin Portal):**
   - تسجيل الدخول (`admin` / `admin`).
   - يدخل مباشرة إلى لوحة المدير العام لاعتماد المحلات والرقابة والإشراف على المنصة.

> 💡 في صفحة تسجيل الدخول، تتوفر تبويبات مستقلة لكل بوابة مع أزرار تجربة سريعة بنقرة واحدة لكل دور.

## 🎨 نظام التصميم والألوان المعتمد (Design System)

- **البرتقالي الأساسي (Primary Orange):** `#FF7A00` — الشعار، أزرار الشراء، الفئات النشطة، التركيز.
- **الكحلي الداكن (Dark Navy):** `#0F1F3D` — العناوين، النصوص الرئيسية، أزرار "أضف إلى السلة"، شارة المحل.
- **الأخضر (Green):** `#1FA971` — الأسعار بالأرقام المشرقية العربية (مثال: `٢٥٠ ج.م`)، المجموع، شارات التوفر.
- **الخلفية (Background):** `#F6F8FB` مع توهج برتقالي ناعم في الجانب الأيمن.
- **الكروت (Cards):** `#FFFFFF` مع زوايا ناعمة (14–18px) وظلال رقيقة.
- **خلفية صور المنتجات:** بيتش فاتح `#FFF0E2`.
- **الشعار:** مربع برتقالي بحواف دائرية يحمل حرف "د" باللون الأبيض تليه كلمة "دليلى".

## ✨ المميزات الرئيسية للموقع

1. **صفحة العميل (Customer Experience):**
   - مطابقة دقيقة للتصميم المرجعي.
   - شريط علوي أنيق يضم الشعار، اسم المحل "الجرابات والإكسسوارات"، رابط لوحة التحكم، شريط بحث حي وسريع، وزر السلة مع عداد ديناميكي.
   - عمود فلاتر أيمن يضم تصنيفات المنتجات (الكل، جرابات، اسكرينات، شواحن، كابلات)، قائمة توافق الهواتف (iPhone 15 Pro, Samsung S24 Ultra, Xiaomi 13T)، وزر مسح الفلاتر.
   - شبكة منتجات 4 أعمدة ريسبونسف تعرض المنتجات مع مؤشرات المخزون (متوفر، كمية محدودة، نفد المنتج).
   - سلة مشتريات منبثقة بتحديث فوري وتعديل للكميات وإتمام الطلب مع نافذة إشعار نجاح برقم طلب فريد.

2. **لوحة تحكم صاحب المحل (Store Owner Dashboard):**
   - بطاقات إحصائية ذكية: إجمالي المنتجات المعروضة، عدد التصنيفات، إجمالي المبيعات المحققة.
   - إعداد بيانات المحل (الاسم، المنطقة، الهاتف، الوصف، الشعار) مع نظام مراجعة الإدارة (قيد المراجعة / معتمد / مرفوض).
   - إضافة منتجات يدوياً مع معاينة فورية لرفع الصورة، ومفتاح توفر المخزون.
   - استيراد جماعي للمنتجات (Bulk Upload) يدعم ملفات CSV و Excel (.xlsx) عبر SheetJS، مع فحص سلامة البيانات وجدول معاينة وتحديد المنتجات المراد استيرادها، وتحميل نموذج جاهز.
   - جدول إدارة المخزون مع إمكانية تعديل وحذف وتبديل حالة التوفر بضغطة زر.

3. **لوحة تحكم المدير (Admin Dashboard):**
   - مراجعة طلبات المحلات الجديدة مع إمكانية القبول أو الرفض الفوري وتأثيرها المباشر على صفحة العميل.
   - استعراض كافة المحلات والمنتجات التابعة لها.
   - الرقابة والإشراف: إخفاء أي منتج مخالف مع ذكر السبب وتحديث ظهوره في صفحة العميل فورًا.

4. **إعادة ضبط البيانات (Reset Demo):**
   - يوجد رابط في أسفل الصفحة لإعادة ضبط بيانات المتجر والمخزون إلى حالتها الأولية بضغطة واحدة.
